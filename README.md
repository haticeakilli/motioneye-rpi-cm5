# rpi-cm5-nvr-comparison

Bu çalışmada, Raspberry Pi CM5 üzerinde farklı açık kaynak NVR çözümleri kurulmuş ve bu çözümler performans, stabilite, kayıt biçimi ve yapılandırma zorlukları açısından karşılaştırılmıştır.

Donanım:
Raspberry Pi Compute Module 5
CM5 IO Board
USB Kamera / CSI Kamera (RPi V2 Camera)
NVMe SSD (harici depolama)

Yazılım:
Debian 13 (Trixie)
Docker & Docker Compose
MotionEye (manuel / venv)
Shinobi (Docker)
ZoneMinder
Frigate (Docker)
FFmpeg, V4L2
